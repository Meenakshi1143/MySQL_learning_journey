# Student Management System

## Project Overview

The **Student Management System** is a relational database project developed using **MySQL**.

The project is designed to manage and analyze student academic and administrative information in a structured relational database.

The system manages information related to:

- Students
- Departments
- Instructors
- Courses
- Enrollments
- Attendance
- Examinations
- Results
- Payments

The project demonstrates the practical implementation of database design concepts and SQL operations ranging from basic data retrieval to advanced analytical queries.

The database demonstrates the implementation of:

- Database creation
- Table creation
- Primary keys
- Foreign keys
- NOT NULL constraints
- UNIQUE constraints
- DEFAULT constraints
- CHECK constraints
- ENUM data types
- Data insertion
- Referential integrity
- One-to-many relationships
- Many-to-many relationship handling
- INNER JOIN
- LEFT JOIN
- Multiple-table JOINs
- Aggregate functions
- GROUP BY
- HAVING
- ORDER BY
- LIKE
- BETWEEN
- DISTINCT
- Subqueries
- EXISTS
- NOT EXISTS
- CASE expressions
- COALESCE()
- Attendance percentage calculation
- Student performance analysis
- Payment analysis
- RANK()
- DENSE_RANK()
- PARTITION BY
- SQL Views
- Data analysis using SQL

# Objectives

The main objectives of this project are:

1. To design a relational database for managing student information.
2. To identify entities, attributes, relationships, and cardinalities.
3. To create a structured database using MySQL.
4. To maintain data integrity using primary keys and foreign keys.
5. To implement NOT NULL, UNIQUE, DEFAULT, CHECK, and ENUM constraints.
6. To manage student enrollment information.
7. To track student attendance.
8. To manage course examinations.
9. To store and analyze examination results.
10. To manage student fee/payment information.
11. To perform SQL queries from basic to advanced levels.
12. To analyze student academic performance.
13. To calculate student attendance percentages.
14. To identify students with attendance below 75%.
15. To identify high-performing students.
16. To rank students based on their academic performance.
17. To identify top-performing students within departments.
18. To analyze examination-wise performance.
19. To analyze student payment status.
20. To create reusable reports using SQL Views.
