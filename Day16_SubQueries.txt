SUB QUERIES
-----------
What is Sub Query ?
-A Sub-Query is Query inside another Query.
-It is Also Called as 'Inner Query' , 'Nested Query' , 'Inner select

General Syntax
--------------
Select column-list
from table
where column OPERATOR(select column from table where condition)

Purpose of Subquery
-------------------
To break down complex problems into smaller queries
To use the result of one query as input to another.
To avoid multiple steps(Write in a single query instead of temp tables)

Types Of SubQueries
-------------------
1. single-row-subquery
2. multi-row-subquery
3.nested-sub-query
4.corelated subquery
5.Exists/not Exists sub query.

1.single-row-subquery :
-----------------------Single Row sub queries returns exactly one row and one column. They use comparison operators (< ,  <=, >=, =, !=)

Characterstics
--------------
Returns only one value.
Can use single-value comparison operators
if sub query returns no rows or multiple rows. it causes an error.

Syntax
------
select column
from table
where column operator(select column from table where condition)

2.Multi-row-subquery
--------------------
(a) Multi-row-subqueries with IN.
-a multi row subquery returns more than one row. the IN operator is used when you want to compare a value with multiple values return by the subquery.

Characterstics
--------------
returns multiple rows.
use the IN operator.
checks if a value exists in the list returned by the subquery.
equivalent to multiple or conditions.
most commonly used for matching values.

Syntax
------
select column
from table
where column IN(select column from table where condition)

(b)Multi-Row-subquery (ANY/SOME)
--------------------------------
Multi row sub queries returns multiple rows. when using ANY or SOME. The condition is true if it matches at least one one value returned by the subquery

Characteristics
---------------
return multiple values
any and some are interchangeable
condition is true if any of the values satisfy the condition.
often  usd with IN,>ANY ,<ANY,=ANY etc.

Syntax
------
select column
from table
where column ANY/SOME(select column from table where condition)

(c) Multi-row-subquery(ALL)
---------------------------
The All operator means the condition must be true for all values returned by the sub query.

Characterstics
--------------
condition must be true for all values in the subquery result
often used with >all,<all,>=all,<=all
>all means greater than the maximum value
<all means less than the minimum value 

Syntax:
-------
select column
from table
where column ALL(select column from table where condition)

3.Nested Sub query
------------------
Nested sub query are subqueries within subqueries. they can be multiple levels deep and are executed from the innermost to the outermost

characterstics
---------------
multiple levels of nesting.
inner queries execute first
can combine different types of sub-queries.
useful for complex conditions.

Syntax
------
select column-list from table
where column=(select column from table where column =(select column from table where condition));

4. Corelated subquery
---------------------
corelated subqueries are subqueries that reference column from the outer query. unlike regular subqueries that are execute once. 
corelated subqueries execute once for each row proceed by the outer subquery.

Chracterstics
-------------
reference column from the outer query
executes multiple times(once per outer row)
cannot be executed independently.
often used with exists, not exists.
generally slower than non-corelated subqueries.

Syntax
------
select columns
from table1 outer_alias
where condition(select column
                               from table2 inner_alias
                                            where inner_alias.column=outer_alias.column);

5.Exists/ Not Exists subquery
-----------------------------
Exists is used to test whether a subquery returns any rows, it returns true if the sub query returns

characterstics
--------------
return TRUE/FALSE(Boolean result)
more efficient than IN  for large datasets.
often used with corelated subquries
stops execution as soon as first match is found.
select clause is in Exists doesn't matter

Syntax
------
select columns from table1
where exists(select 1 from table2 where condition);

Syntax
------
select columns
from table1
where not exists(select 1 from table2 where condition);
