Numeric Functions
-----------------

abs(): Absolute value of a number
ceil(): Rounded up of a integer
floor(): Rounded down
round(): Round to a specific number of digits
mod(): Returns modulo value
pow(): Exponential value
sqrt(): Return sqaure root of a number
