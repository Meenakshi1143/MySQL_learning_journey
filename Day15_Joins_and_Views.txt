Joins
-----

--> A join in MySQL is used to combine rows from two or more tables based on related columns.

Example: 
employee table - employee details
departments - department details

If you want to see which employee belongings to which department you need to join these two tables.

why do we need joins?
1. To fetch data from multiple tables in a single query.
2. To reduce data duplication(instead of keeping everything one table)
3. To implement relations like (one - to - one, one - to - many, many - to - many, many - to - one) in databases
4. To generate reports and analytics combining different datasets

Types of Joins
--------------
1. Inner Join
2. Left Join
3. Right Join
4. Full Join
5. Cross Join
6. Self Join

Inner Join:
--> returns only the rows that have matching values in both tables.

Syntax:
select columns
from table1
inner join table2
on table1.common_column = table2.common_column;

Left Join:
--> returns all rows from left table and the matched rows from the right table. If no match, Null values appear for right table columns.

Syntax:
select columns
from table1
left join table2
on table1.common_column = table2.common_column;


Right Join:
--> returns all rows from left table and the matched rows from the left table. If no match, Null values appear for left table columns.

Syntax:
select columns
from table1
right join table2
on table1.common_column = table2.common_column;

Full join:
--> To simulate use the union of left join and right join

Syntax:
select columns
from table1
left join table2
on table1.common_column = table2.common_column;
union
select columns
from table1
right join table2
on table1.common_column = table2.common_column;


Cross Join:
--> Returns cartesian product - every row from the first table with every row from the second table.

Syntax:
select columns
from tablle11
cross join table2;

Self Join:
--> A table Joined with itself

Syntax:
select a.columns, b.columns
from table1 a
inner join table1 b
on a.common_column = b.common_column;

VIEWS
-----
--> View is a virtual table in MySQL. Built it from the result of stored select statement. It looks and behaves like regular table when you query it.
--> You can select from it, filter it and join it. But it doesn't store any data on its own. Every time view is queried, MySQL runs its underlying select statement against in real tables and returns the result.

Why do we need View:
--------------------
1. Simplify complex queries
2. Reuse query logic
3. Data Security
4. Logical Data independence.

Advantages:
-----------
- Security
- Reusability
- Simplicity
- Consistency
- Maintainability
- Custom data presentation
- No extra storage cost

Creating VIEWS
--------------
create view view_name as
select columns from table
where condition


altering views
--------------
alter view view_name as
select new_column
from new_tables.

dropping VIEW
-------------
drop view view_name;
drop view if exists view_name;
