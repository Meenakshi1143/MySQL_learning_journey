***SET OPERATORS 
----------------
1. Union: Combines results from two queries and remove duplicate rows. Columns must have the same number and type
2. Union All: Combines results from two queries and Including duplicate. Columns must have the same number and type
3. Intersect: Return rows that are common to both queries. Columns must have the same number and type. 
	Note: MySQL doesn't support intersect directly
4. Minus: Return rows from the first query that are not present in the second query columns must have the same number and type
	Note: MySQL doesn't support Minus directly
